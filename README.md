# 학사일정 · 수업일수표

교직원용 **생성기**에서 입력한 학사일정을, 누구나 보기 쉬운 **열람 페이지(뷰어)** 로 공유하는 프로젝트입니다.
백엔드 없이 정적 페이지만으로 동작합니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | **뷰어(열람 전용)** — 학사 월력 · 수업일수표 · 전체 일정을 연도별로 표시. 상단 **관리자** 버튼으로 생성기 진입 |
| `generator.html` | **생성기(관리자)** — 개강·종강일, 휴업일, 시험, 행사 등을 입력·인쇄·엑셀 내보내기. **비밀번호 잠금** |
| `data.json` | 뷰어에 게시되는 공식 데이터 (생성기의 "뷰어 데이터 저장" 버튼으로 생성) |

주소는 뷰어 하나만 공유하면 됩니다. 관리자는 뷰어 상단의 **관리자** 버튼(또는 하단 링크)으로 비밀번호를 입력해 생성기에 들어갑니다.

### 관리자 비밀번호

- 소스에는 비밀번호 원문이 아니라 **SHA-256 해시**만 저장됩니다.
- 생성기 상단의 **비밀번호** 버튼에서 변경할 수 있습니다: 현재 비밀번호 확인 → 새 비밀번호 2회 입력.
- 변경 직후에는 그 브라우저에만 적용되며, 뷰어의 **[지금 게시]**(아티팩트) 또는 `data.json` 교체 커밋(Pages)을 하면 게시 데이터에 해시가 실려 **모든 기기의 잠금에 적용**됩니다.
- 정적 페이지 특성상 서버 인증이 아닌 **간이 잠금**입니다(열람자의 실수 진입 방지 용도). 게시 권한 자체는 호스팅 계정 소유자에게만 있으므로, 다른 사람이 게시본을 바꿀 수는 없습니다.

## 사용 흐름

1. `generator.html` 에서 학년도·학기별 일정을 입력합니다. (입력값은 브라우저에 자동 저장)
2. 다른 사람에게 보여줄 때는 아래 중 하나를 사용합니다.
   - **즉시 게시 (Claude 아티팩트 호스팅)** — 뷰어를 열면 생성기 입력값이 게시본과 다를 때 상단에 "지금 게시" 배너가 나타납니다(소유자에게만 동작). 누르면 같은 주소의 모든 열람자에게 즉시 반영됩니다.
   - **뷰어 공유 링크** 버튼 → 입력한 데이터가 담긴 링크가 복사됩니다. 링크를 받은 사람은 바로 열람할 수 있습니다.
   - **뷰어 데이터 저장** 버튼 → `data.json` 이 다운로드됩니다. 이 파일을 저장소의 기존 `data.json` 에 덮어써 커밋하면(GitHub Pages 호스팅), 뷰어 주소로 접속하는 모든 사람에게 반영됩니다.
3. **다음 연도 일정**도 생성기에서 학년도만 바꿔 입력하면, 뷰어의 연도 선택(◀ ▶)으로 바로 열람할 수 있습니다. 입력된 데이터가 있는 학년도는 목록에 `●` 로 표시됩니다.

같은 브라우저에서는 별도 내보내기 없이도 뷰어가 생성기의 입력값(localStorage)을 자동으로 읽어옵니다.

### 로컬(PC 파일)에서 만든 데이터 옮기기

입력값은 입력한 그 브라우저·주소에만 저장되므로, 로컬 파일로 작업한 데이터는 파일로 옮깁니다.

1. 이 저장소의 `generator.html` 을 내려받아 **로컬 파일로, 기존에 작업하던 같은 브라우저에서** 엽니다 → 기존 입력값을 그대로 읽어옵니다 (같은 저장 키 사용).
2. **[뷰어 데이터 저장]** → `data.json` 파일이 내려받아집니다.
3. 호스팅된 생성기에서 **[가져오기]** → 파일 선택으로 `data.json` 업로드.
4. 뷰어로 이동해 **[지금 게시]** (또는 Pages라면 `data.json` 교체 커밋).

뷰어의 데이터 우선순위: **공유 링크(#d=) → 구글시트(설정된 경우) → 같은 브라우저의 생성기 입력값(localStorage) → 페이지에 게시된 데이터 → data.json → 기본값**

## 구글시트 연동 (일정 데이터 원본)

`index.html` 상단의 `SHEET_ID` 상수에 구글시트 ID를 넣으면, 뷰어가 GitHub의 `data.json` 대신 **구글시트를 직접 읽어옵니다**. 시트에서 일정을 고치고 저장하면 사이트 새로고침 시 바로 반영되므로, GitHub에 파일을 올리는 절차가 필요 없습니다.

- 조건: 시트를 **공유 → 링크가 있는 모든 사용자(뷰어)** 로 설정해야 합니다.
- 시트 형식(첫 칸 `종류` 기준): `학년도` / `표시학기` / `주차` / `의견수렴`(시작·종료일 채우면 뷰어에 의견 제출 버튼 표시) / `우선표시`(아래 참고) / `학기`(학기키·개강일·종강일) / `일정`(학기키·시작일·종료일·명칭·분류) — `메모` 행과 모르는 행은 무시됩니다.
- 분류: `휴업일` `시험` `보강` `행사` `학사`. 날짜는 `2027-04-19`, `2027. 4. 19` 형식 모두 인식.
- `비밀번호해시` 행(A열 `비밀번호해시`, B열에 SHA-256 해시 64자)을 넣으면 관리자 비밀번호가 모든 기기·브라우저에 동일하게 적용됩니다.
- 시트를 읽지 못하면(공유 해제·네트워크 오류) 자동으로 기존 `data.json` 으로 폴백합니다.

### 뷰어가 처음 보여주는 학년도

1. **우선 표시가 유효하면 그 학년도** — 생성기 상단의 **[우선 표시]** 버튼에서 학년도·기간을 설정하고 [시트에 반영]하면 됩니다(시트에 직접 넣을 때는 A열 `우선표시`, B열 학년도, C·D열 시작일·종료일). 지정한 기간 동안(날짜를 비우면 상시) 뷰어가 그 학년도를 먼저 보여주고, 상단에 "○○학년도 학사일정을 우선 안내하고 있습니다" 배너를 띄웁니다. 다음 학년도 일정 확정 후 점검·안내 기간에 미래 일정을 먼저 보여주고 싶을 때 사용하며, 기간이 지나면 자동으로 아래 기본 동작으로 돌아갑니다(설정 해제 불필요).
2. `연도잠금` 이 잠금 상태(기본, 생성기의 **[뷰어 표시 연도]** = "이 학년도만")면 `학년도` 행의 학년도.
3. 잠금을 해제(생성기 [뷰어 표시 연도] = "전체 열람", 시트로는 `연도잠금` = `해제`)하면 **오늘 날짜가 속한 학년도**(3월~다음해 2월 기준, 입력된 데이터가 있을 때) — 연도 이동(◀ ▶)도 함께 열립니다.

> 우선 표시를 [시트에 반영]으로 쓰려면 접수 스크립트가 최신이어야 합니다 — `apps-script.gs` 내용을 다시 붙여넣고 **[배포] → [배포 관리] → 새 버전으로 배포**해 주세요(주소는 그대로 유지됨).
- `SHEET_ID` 를 빈 문자열(`''`)로 두면 연동이 꺼지고 기존 방식으로만 동작합니다.

### 의견 바로 제출 + 관리자 [반영] 승인 (선택, Apps Script)

기본 의견 수렴은 파일 저장·전달 방식이지만, 시트에 **접수 스크립트**를 붙이면 부서가 [의견 제출]을 누르는 즉시 시트의 `의견` 탭에 쌓이고, 관리자는 **생성기의 [부서 의견 수렴] 카드 → [의견 검토]**에서 [반영] 클릭 한 번으로 시트의 일정을 직접 수정할 수 있습니다. (의견 수렴 기간 설정도 같은 카드의 [기간 설정] → [시트에 반영]으로 관리합니다. 생성기를 열면 시트에 저장된 의견수렴·우선표시·연도잠금 설정을 자동으로 읽어와 표시합니다.)

설치(한 번만, 약 5분):

1. 연동 시트 열기 → **확장 프로그램 → Apps Script** → 저장소의 `apps-script.gs` 내용 전체 붙여넣기
2. 코드 상단 `ADMIN_PW` 를 **사이트 관리자 비밀번호와 동일하게** 수정 후 저장
3. **[배포] → [새 배포] → 유형: 웹 앱** — 실행 계정 **나**, 액세스 권한 **모든 사용자** → 배포
4. 발급된 웹 앱 URL(`…/exec`)을 복사해, 시트에 행 추가: **A열 `제출주소`, B열에 URL**

이후 뷰어가 `제출주소` 를 읽으면 자동으로 직접 제출 모드로 전환됩니다(행을 지우면 파일 방식으로 복귀). [반영]은 스크립트의 `ADMIN_PW` 로 재검증되며, 제출된 의견은 시트가 링크 공유 상태이므로 링크를 아는 사람은 열람할 수 있습니다.

## 웹에 게시하기 (GitHub Pages)

저장소 **Settings → Pages → Branch** 에서 게시할 브랜치와 `/ (root)` 를 선택하면
`https://<계정명>.github.io/<저장소명>/` 주소로 뷰어가 공개됩니다.
(`index.html` 이 뷰어이므로 기본 주소가 곧 열람 페이지입니다. 생성기는 `/generator.html`)

## 내장 기능

- **학사일정 검색**: 뷰어 상단 검색창에서 입력된 모든 학년도의 일정을 이름·분류(휴업일/시험/보강/행사/학사)·날짜로 검색 — 결과를 누르면 해당 학년도의 월력으로 이동해 날짜를 강조 표시 (서버 없이 브라우저에서만 동작)
- 한국 공휴일 자동 계산(2025~2030): 고정 공휴일 + 설날·추석·부처님오신날(음력) + 대체공휴일 규칙
- 요일 기준 수업일수 자동 계산, 수업일수 1/4·2/4·3/4 분기점·종강일 표시
- 인쇄(A4)·엑셀 내보내기(생성기), 반응형(모바일) 지원
